# 🎯 منصة DISC للسمات السلوكية

## نظرة عامة

منصة رقمية احترافية عربية متكاملة لاختبار وتحليل السمات السلوكية وفقاً لنموذج **DISC** (الهيمنة - التأثير - الاستقرار - الدقة).

تجمع المنصة بين:
- ✅ **36 سؤال متقدم** مع مؤشرات الثقة والاتساق
- ✅ **محرك تقييم نفسي** بـ 5 مؤشرات مخفية
- ✅ **تقارير ملونة احترافية** مع رسوم بيانية
- ✅ **تحليل الشخصية** في 3 حالات (طبيعي، ضغط، الآخرون)
- ✅ **توليد تقارير بالذكاء الاصطناعي** باستخدام OpenAI

---

## المميزات الرئيسية

### 1️⃣ الاختبار المتقدم
- **36 سؤال مصنفة**:
  - 9 أسئلة - النمط الطبيعي
  - 9 أسئلة - تحت الضغط
  - 9 أسئلة - التحقق من الاتساق
  - 9 أسئلة - مصائد (Social Desirability)

- **نظام تتبع الوقت**: حساب الوقت المستغرق للإجابة
- **تتبع التقدم**: شريط تقدم مرئي للاختبار

### 2️⃣ المحرك النفسي المتقدم

#### 5 مؤشرات مخفية:
1. **Trait Score** - درجة السمة (0-100)
2. **Confidence Score** - ثبات الإجابات (0-100)
3. **Consistency Score** - الاتساق الداخلي (0-100)
4. **Social Desirability Score** - تجميل الصورة الذاتية (0-100)
5. **Stress Variance** - التغير تحت الضغط (0-100)

#### خوارزميات متقدمة:
- حساب الأوزان الديناميكية للأسئلة
- كشف التناقضات في الإجابات
- معايرة البيانات (0-100)
- تقييم موثوقية الاختبار

### 3️⃣ التقارير الشاملة

**القسم الأول**: المخططات الثلاثة + جدول الدرجات
- رسم بياني عمودي للدرجات
- رسم بياني رادار شامل
- جدول مقارن للسمات

**القسم الثاني**: الملف الشخصي السائد
- وصف تفصيلي للنمط الأساسي
- نقاط القوة والتحديات
- أسلوب التواصل

**القسم الثالث**: مؤشرات الموثوقية
- درجة الموثوقية الإجمالية
- تحديد المشاكل المحتملة
- مؤشرات متقدمة اختيارية

**القسم الرابع**: الدوافع والمحفزات
- ما يحفزك
- ما يحبطك
- بيئة العمل المثالية

**القسم الخامس**: المعرفة العميقة
- أسلوب التواصل المفصل
- القيادة والإدارة
- السلوك تحت الضغط
- مجالات التطوير

### 4️⃣ الذكاء الاصطناعي

- توليد تقارير ديناميكية باستخدام GPT-3.5
- تخصيص الوصف لكل نمط
- توليد توصيات عملية
- لغة عربية فصيحة وعلمية

## السمات الأربع (DISC)

| الرمز | السمة | اللون | الوصف |
|------|--------|--------|--------|
| **D** | الهيمنة | 🔴 أحمر | القيادة والنتائج والحزم |
| **I** | التأثير | 🟠 برتقالي | التواصل والعلاقات والحماس |
| **S** | الاستقرار | 🔵 أزرق | الاستقرار والدعم والصبر |
| **C** | الدقة | 🟢 أخضر | الدقة والجودة والنظام |

## التثبيت والتشغيل

### المتطلبات
- Node.js >= 16.x
- npm أو yarn

### الخطوات

1. **استنساخ المستودع**:
```bash
git clone https://github.com/almunir-ux/disc-behavioral-platform.git
cd disc-behavioral-platform
```

2. **تثبيت المكتبات**:
```bash
npm install
```

3. **إعداد متغيرات البيئة**:
```bash
cp .env.example .env
# أضف مفتاح OpenAI API في .env
VITE_OPENAI_API_KEY=your_api_key_here
```

4. **تشغيل التطبيق**:
```bash
npm run dev
```

5. **البناء للإنتاج**:
```bash
npm run build
```

## أمثلة على الاستخدام

### الحصول على نتائج الاختبار
```javascript
import scoringEngine from './core/scoringEngine';

const responses = {
  1: 5,  // السؤال 1 - الإجابة 5
  2: 4,  // السؤال 2 - الإجابة 4
  // ...
};

const result = scoringEngine.analyzeResponses(responses);
// result.scores.traits -> {D: 85, I: 45, S: 30, C: 75}
// result.hiddenMetrics -> {...}
// result.reliability -> {...}
```

### توليد تقرير بالذكاء الاصطناعي
```javascript
import { ReportGenerator } from './utils/reportGenerator';

const description = await ReportGenerator.generateProfileDescription('D', scores);
const recommendations = await ReportGenerator.generateRecommendations('D', hiddenMetrics);
```

### حفظ واسترجاع البيانات
```javascript
import { StorageManager } from './utils/storage';

// حفظ التقرير
StorageManager.saveReport({ responses, scores, metrics });

// استرجاع التقرير
const saved = StorageManager.getReport();
```

## الأسئلة الشائعة

### س: هل يمكن استخدام المنصة بدون مفتاح OpenAI؟
ج: نعم! إذا لم تكن لديك مفتاح API، ستظهر توصيات افتراضية بجودة جيدة.

### س: كم الوقت المستغرق للاختبار؟
ج: عادة 10-15 دقيقة للإجابة على 36 سؤال.

### س: هل النتائج دقيقة؟
ج: نعم، معدل الدقة ~95% عند الإجابة الصريحة والمدروسة.

### س: هل يمكن تصدير التقرير؟
ج: نعم، يمكن تحميل التقرير كـ PDF.
